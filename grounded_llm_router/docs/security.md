# NimbusStack Security & Compliance

## Data Encryption
All data is encrypted in transit using TLS 1.3 and at rest using AES-256. Encryption keys are rotated every 90 days and managed through a dedicated key management service.

## Compliance Certifications
NimbusStack is SOC 2 Type II certified and undergoes an annual third-party audit. We are GDPR compliant for all customers with data residency requirements in the EU. We are not currently HIPAA compliant and do not recommend NimbusStack for storing protected health information.

## Data Residency
Enterprise customers can choose to have their data stored exclusively in EU, US, or APAC regions. Starter and Growth tier customers' data is stored in the US region by default.

## Access Control
NimbusStack supports role-based access control (RBAC) with four default roles: Admin, Editor, Viewer, and Billing. Enterprise customers can define custom roles. Single Sign-On (SSO) via SAML 2.0 is available on the Enterprise tier only.

## Incident Response
In the event of a security incident affecting customer data, NimbusStack commits to notifying affected customers within 72 hours of confirming the incident, in line with GDPR breach notification requirements.

## Penetration Testing
NimbusStack commissions an independent penetration test twice per year. Summary reports are available to Enterprise customers under NDA upon request.
