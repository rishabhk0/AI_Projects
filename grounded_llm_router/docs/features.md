# NimbusStack Features

## Core Platform
NimbusStack is a workflow automation platform that lets teams connect internal tools, build automated pipelines, and monitor them from a single dashboard.

## Integrations
NimbusStack natively integrates with Slack, GitHub, Jira, Google Workspace, and Salesforce. Additional integrations are available through our public API and a partner marketplace of community-built connectors.

## Automation Builder
The Automation Builder is a visual, drag-and-drop editor for creating multi-step workflows without writing code. Growth and Enterprise tiers unlock conditional branching and scheduled triggers; the Starter tier only supports simple linear workflows.

## Version History
All workflow changes are versioned automatically. Users can roll back to any previous version of a workflow from the version history panel. Version history is retained for 90 days on Growth, and indefinitely on Enterprise.

## Mobile App
NimbusStack has a mobile app for iOS and Android that supports monitoring and approvals, but workflow editing is only available on desktop/web.

## Offline Mode
NimbusStack does not currently support offline mode. An internet connection is required to view or edit workflows.
